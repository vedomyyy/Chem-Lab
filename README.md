# ХимЛаб — Лабораторный журнал расходных материалов

## Описание и цель

Веб-приложение для учёта расходных материалов в химической лаборатории. Позволяет вести склад реактивов и лабораторного оборудования, фиксировать приход и расход, формировать отчёты и получать уведомления о низком уровне запасов.

**Вариант 6** — учебный проект по дисциплине «Веб-программирование».

---

## Технологии

- **Backend:** PHP 8.2
- **БД:** MySQL 8.4 / MariaDB
- **Frontend:** Bootstrap 5.3, HTML5, JavaScript (ванильный)
- **Сервер:** Apache / Nginx + PHP-FPM (или OpenServer / XAMPP для локальной разработки)

---

## Инструкция по установке

### 1. Клонировать / скопировать файлы

Скопируйте содержимое папки `public_html/` в корень веб-сервера (например `htdocs/` в XAMPP или `www/` в OpenServer).

### 2. Создать базу данных

Выполните SQL-скрипт `database.sql` в phpMyAdmin или через консоль:

```bash
mysql -u root -p < database.sql
```

### 3. Настроить подключение к БД

Откройте файл `includes/db.php` и задайте параметры:

```php
define('DB_HOST', 'localhost');  // хост MySQL
define('DB_PORT', '3306');
define('DB_NAME', 'chem_lab_inventory');
define('DB_USER', 'root');       // ваш пользователь
define('DB_PASS', '');           // ваш пароль
```

### 4. Запустить сервер и открыть приложение

Откройте браузер и перейдите по адресу `http://localhost/` (или `http://localhost/public_html/` — в зависимости от настройки).

- [x] Приход (с указанием поставщика и комментария)

- [x] Запрет списания больше, чем есть на складе (серверная + клиентская валидация)

- [x] Журнал всех операций
